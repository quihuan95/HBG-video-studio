# Bộ Video Rule mẫu cho Production Profile

Copy hai file Rule trong thư mục này vào cùng một folder trên Google Drive, sau đó
điền Folder ID hoặc URL đó vào trường **Folder RULES** của Content Profile.

Tên file phải giữ nguyên:

- `BRAND_FACTS.md`: thông tin thật về thương hiệu, sản phẩm và CTA.
- `VIDEO_RULE.md`: toàn bộ rule content, footage, voice, timeline, subtitle,
  intro/outro, chuyển cảnh, logo, nhạc, review và render.
Sau khi sửa file trên Drive, bấm **Đồng bộ Rule + Sheet**. Hệ thống chỉ tạo
Rule version mới nếu nội dung Markdown thực sự thay đổi. `CONTENT_RULE.md` và
`PRODUCTION_CONFIG.json` là định dạng cũ và không còn được hệ thống đọc.
