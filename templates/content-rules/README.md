# Bộ Rule mẫu cho Content Profile

Copy bốn file trong thư mục này vào cùng một folder trên Google Drive, sau đó
điền Folder ID hoặc URL đó vào trường **Folder RULES** của Content Profile.

Tên file phải giữ nguyên:

- `CONTENT_RULE.md`: giọng điệu, cấu trúc nội dung và điều cấm.
- `BRAND_FACTS.md`: thông tin thật về thương hiệu, sản phẩm và CTA.
- `IMAGE_RULE.md`: tỷ lệ, phong cách, logo, chữ và quy tắc chọn footage/ảnh.
- `PUBLISH_CONFIG.json`: cấu hình xuất bản có cấu trúc; file này là tùy chọn.

Sau khi sửa file trên Drive, bấm **Đồng bộ Rule + Sheet**. Hệ thống chỉ tạo
Rule version mới nếu nội dung Markdown thực sự thay đổi.
